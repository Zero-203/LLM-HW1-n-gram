# n-gram 实验配置记录

- **状态：** 执行前配置记录；实际执行设置与偏离项见第 8 节，结果见 `experiment_report.md`
- **配置版本：** 1.0
- **随机种子：** 42
- **适用语料：** `data/raw/199801.txt` 至 `data/raw/199806.txt`
- **原始文件原则：** `data/raw/` 中的语料和说明文档只读，不覆盖、不直接清洗。

## 1. 语料来源、内容与格式

### 1.1 来源与使用说明

`data/raw/shengming.doc` 为随语料提供的说明文档。文档将语料说明为“PFR 人民日报标注语料库（版本 1.0）”，称其以 1998 年《人民日报》语料为对象，由人民日报社新闻信息中心、北京大学计算语言学研究所和富士通研究开发中心有限公司共同制作；文档说明，研究或论文中使用该语料时应注明来源。文档还特别提到当时公开发布的是 1 月份语料。

当前工作区列有 199801 至 199806 六个月份文件。开展实验或对外发布前，应核对这些文件各自适用的授权/使用条件；保留原始说明，并在报告中注明语料来源。不要仅凭说明文档中关于 1 月份公开发布的文字，推断其余月份可不受限制地再分发。

### 1.2 内容与记录结构

语料为中文新闻文本，已进行分词并附词性标注。每条正文记录前有段落标号，格式为：

```text
日期-版面-文章-段落/标记
```

例如 `19980101-01-001-001/m` 表示 1998-01-01、版面 01、文章 001、段落 001。编号用于识别文章与段落，不属于正文。空行表示文章间隔，可作为文章边界校验信号。文章段落中可能包含标题、正文、落款、日期、记者/来源信息等；落款和日期有时也是独立段落。

正文通常由空白分隔的“词语/词性”单元组成，例如 `迈向/v`、`希望/n`、`新华社/nt`、`。/w`。样例中还有 `[中国/ns 政府/n]nt` 这样的组合标注：括号内为实际分词，外围标签表示组合类别。语料包含中文标点、数字、日期、专名等。

### 1.3 解析与核验约定

- 以完整段落编号作为元数据解析；文章分组键取“日期-版面-文章”，不可把编号最后的段落序号误作文章号。
- 用明确的词性分隔规则解析词语与词性（优先按最后一个 `/` 分隔），抽样检查含标点、斜线或组合标注的行。
- 对组合标注剥离方括号和外围类别标记，保留括号内的词语及其原有次序，不重复生成组合词。
- 记录空行、编号切换和文章分组结果的一致性；检查文件编码后，以 UTF-8 写入清洗结果，原文件编码和内容不变。
- 在正式训练前抽查每个月份文件的开头、中部、末尾及组合标注/文章末段，确认文件间格式一致。若发现格式例外，记录处理规则和受影响记录数。

## 2. 清洗规则

1. 删除每段开头的段落编号及编号的 `/m` 标记。
2. 删除词性标签（如 `/v`、`/n`、`/w`），只保留词语本身；组合标注只保留方括号内的实际词语，去掉方括号和外围类别标签。
3. 保留正文词语、标点、数字、正文日期、署名/记者姓名及来源/电头文字。不得仅因日期或落款处于文章末尾就删除。
4. 空行和段落编号用于边界识别，不作为正文 token。空段落不产生 token；异常记录先计数并留样，不静默丢弃。
5. 不对专名、数字或全角/半角字符作未经记录的替换。首轮维持原词形；确需统一时，作为单独规范化规则并对全体数据一致应用。
6. 一段只有在人工抽样确认是纯结构性元数据、且不属于正文内容后，才能按明确规则过滤；首轮配置不做此类推断性删除。所有过滤规则应记录样例和数量。
7. 按文章严格隔离 n-gram 上下文。清洗后保留文章/段落边界元数据；计数和评估时不跨文章拼接。以段落为序列单位，在每段起始添加模型需要的 `<s>` 上下文标记，在段尾添加 `</s>`；边界标记不计入普通词汇表。这样也不会在相邻段落间人为制造跨段 n-gram。
8. 清洗结果保存到 `data/interim/`，同时保留来源文件、文章键和段落序号，以支持复核和分组划分。

## 3. 数据集划分

- **划分单位：** 文章，不是行、段落或单个 token。文章键为月份文件标识加“日期-版面-文章”编号，确保同一文章的所有段落只进入一个集合。
- **分层方式：** 每个月份文件分别划分，使训练、验证、测试均覆盖所有月份。
- **比例：** 每月按文章数约 80% 训练、10% 验证、10% 测试。使用随机种子 42，在每月文章键列表上确定性打乱后分配；按整数取整并校正余数，尽可能使每个集合非空。比例按文章数而非 token 数计算，实际比例和文章数另行记录。
- **防泄漏检查：** 划分后验证三集合文章键交集为空；扫描完全重复文章，若发现跨文章重复文本，记录并将重复组整体放入同一集合，避免重复内容泄漏。
- **产物：** 保存每篇文章到集合的映射清单及随机种子到 `data/processed/`，训练/验证/测试 token 序列分别写入 `data/processed/`。词表、未知词映射和任何可学习统计只能由训练集拟合。

## 4. 模型基线与 n 值

- **模型阶数：** 主实验比较 `n = 1, 2, 3, 4, 5, 6`，即 unigram 至 6-gram。对所有阶数使用同一训练/验证/测试划分、清洗和未知词策略。
- **基线：** unigram 是最简单的语言模型基线。额外保留各阶未平滑最大似然估计（MLE）结果，用于观察零概率和覆盖率，不将含零概率的 MLE 困惑度误当成有限、可直接比较的结果。
- **MLE：** 对 unigram，`P(w)=C(w)/N`；对 `n>1`，`P(w|h)=C(h,w)/C(h)`。`N` 和预测事件计数包含段尾 `</s>`，不包含上下文起始标记 `<s>`。若测试事件概率为零，完整序列的负对数似然/困惑度为无穷或未定义。此时报告零概率事件率与 n-gram 覆盖率；如附带仅对非零事件计算的数值，必须标注其仅作诊断、不能与平滑模型困惑度直接比较。
- **加-k 平滑：** 对每个 n 值建立加-k 对照：`P_k(w|h)=(C(h,w)+k)/(C(h)+k|V_pred|)`；unigram 使用相应的总预测事件数作为分母基数。初始方案建议验证集比较 `k ∈ {1, 0.1, 0.01}`；实际执行候选见第 8 节。为每个阶数记录选定的候选；不得用测试集选候选。`V_pred` 为可预测词表，包含训练词表（包括 `<UNK>`）及段尾标记 `</s>`，不包含仅作为上下文的 `<s>`。
- **保存内容：** 在对应 `model/unigram/`、`model/bigram/`、`model/trigram/`、`model/4-gram/`、`model/5-gram/` 或 `model/6-gram/` 目录中保存最终词表、压缩 n-gram 计数和模型元数据。

## 5. 未知词与词表

- 在训练集上统计词频，不查看验证集或测试集的词频来构建词表。
- 将训练集中出现次数 `<= 1` 的词（hapax/单例词）统一映射为 `<UNK>`；这等价于保留训练频次至少为 2 的普通词。若代码参数采用最小保留频次表示，应设 `min_count=2`，避免把“低于 1”误解为会映射单例词。
- 映射训练集中的低频词后，重新统计 unigram 至 6-gram 计数；在词表中显式加入 `<UNK>`。验证集与测试集中不在训练词表的词一律替换为 `<UNK>`，不扩充词表。
- `<UNK>` 是可预测的词元，应计入评估目标 token；`</s>` 作为预测事件计入 `V_pred` 和评估事件数，`<s>` 只用于上下文、不作为预测目标。报告未知词数及其占验证/测试正文 token 的比例。

## 6. 指标和验收记录

- 对每个 n 值和所选平滑参数报告测试集平均负对数似然/交叉熵、困惑度、评估事件数、零概率事件数/率、训练中已观测 n-gram 的事件命中率和未知词比例。若同时报告平滑后的非零概率覆盖率，必须与已观测 n-gram 命中率分开命名；平滑本身可使未见事件获得非零概率。
- 对所有模型采用一致的计数口径：预测正文 token 与 `</s>`，不预测 `<s>`；标点、日期、署名依清洗规则保留并参与评分。
- 仅在验证集上选择加-k 参数；测试集仅用于最终比较。每次运行记录配置版本、随机种子、输入文件清单和输出位置。
- 将指标表写入 `result/metrics/`，图表写入 `result/figures/`，结论、异常和限制写入 `result/reports/`。本文件记录初始实验约定；实际执行结果、偏离项和语料/集合统计见第 8 节及 `experiment_report.md`。

## 8. 实际执行与配置偏离

本节保留初始配置与实际运行的差异，不将计划值追改成仿佛事前已确定的参数。实际实现以 `src/experiment.py` 为准，执行结果以 `result/metrics/*_metrics.json` 和 `model_comparison.csv` 为准。

- 实际加-k 候选为 `k ∈ {1, 0.1, 0.01, 0.001, 0.0001}`，比初始建议增加了 `0.001` 和 `0.0001`；同时实际比较 Good-Turing 与 Katz，因此每阶共有七个平滑候选。各阶仅按验证集交叉熵选择，测试集指标用于报告。
- 实际划分器按文章 token 内容摘要将重复文章组成不可拆分组；用种子 42 打乱后按组大小降序排列，再贪心分配至最接近各月份 8:1:1 目标比例的集合。它不是逐月独立打乱文章并按整数取整的初始方案；实际每月分配数以 `data/processed/split_manifest.json` 为准。
- Good-Turing 实现按当前阶所有已观测 n-gram 统计 count-of-counts；缺少后继频次时使用基于单例/双例计数的回退折扣（无法计算时取 0.5），调整计数不超过原计数。Katz 使用缺少后继频次时折扣回退 0.5，unigram 基底为 add-k `0.01`。详细实现以报告第 3.2 节及代码为准。
- 代码和现有指标文件中的 `ngram_coverage` 实际定义为非零概率事件比例。对平滑模型该值通常为 100%，不代表测试 n-gram 在训练集中出现过；训练中已观测 n-gram 的命中率应看 MLE 基线的非零概率比例。报告据此区分两种口径，避免将平滑覆盖误称为经验命中率。
- 清洗、文章级划分及模型输入使用本文件所列规则。当前工作区统计与最终指标的交叉核对见 `experiment_report.md`；原始数据授权事项仍需在对外使用前另行核实。
